# Mathematics Rendering Engine

A 3D mathematics visualization engine written primarily in C.

The goal of this project is to make mathematical concepts easier to understand by visualizing them in three-dimensional space. It aims to render mathematical functions, equations, coordinate systems, and other mathematical objects as interactive visual representations.

SDL3 is used for window management, rendering output, and input handling, including keyboard and mouse events. The remaining systems are intended to be implemented in C, with minimal external dependencies.

## Goals

- Visualize mathematical functions and equations in 3D.
- Render mathematical objects in a three-dimensional coordinate system.
- Explore mathematical concepts through interactive visualization.
- Build a custom mathematics and rendering system from the ground up.

## Tech Stack

- **Language:** C
- **Library:** SDL3
- **Build System:** CMake

## Status

This project is in its early stages and is under active development.
